OLD PROJECT
If you want a backup, export/download the old database first.
Then use the old provider's console to delete the project itself. Deleting the old project is irreversible and may remove its database, authentication users, storage files, functions, and notification configuration.

IMPORTANT
Do not paste or expose private service-account/service-role keys in browser code or public GitHub files.
