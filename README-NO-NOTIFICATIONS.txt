Nadine Parapharm — notifications removed

This version removes the Finish push setup and Test notification buttons, browser push notifications, notification sounds, service-worker notification code, and the external order-notification API.

Orders still save to Firestore and appear normally in the admin New Orders and Orders & Receipts sections.

Upload all files in this folder to the GitHub repository connected to Vercel, wait for deployment, then press Ctrl+F5 on the website.
