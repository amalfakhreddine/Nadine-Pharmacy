# Desktop alert fix

After deployment:
1. Open the admin site in current Chrome or Microsoft Edge.
2. Reload with Ctrl+F5.
3. Click **Enable computer alerts**.
4. Choose **Allow** when the browser asks.
5. Confirm that the test notification and test sound appear.

If notifications were previously blocked, click the icon beside the website address, open **Site settings**, set **Notifications** to **Allow**, and reload.

The large in-page new-order message and repeating sound work independently of desktop notification permission while the admin page is open.
